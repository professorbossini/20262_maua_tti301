# TTI301 - Aula prática: vetores, funções e closures

## Ponto de partida

Os arquivos `script.js`, `script2.js` e `script3.js` são o estado produzido antes desta aula. Eles cobrem declaração de variáveis, escopo de `var`/`let` e coerção.

## Ordem de execução

Execute os arquivos na ordem abaixo:

```bash
node script4.js
node script5.js
node script6.js
node script7.js
node script8.js
node script9.js
node exercicios_aula_01.js
```

## Conteúdo de cada arquivo

- `script4.js`: comparação com `==`, `===`, `!=` e `!==`.
- `script5.js`: criação, acesso, tamanho e iteração de vetores.
- `script6.js`: `filter`, `map`, `every` e `reduce`.
- `script7.js`: funções tradicionais, anônimas e arrow functions.
- `script8.js`: funções como valores e funções de alta ordem.
- `script9.js`: escopo léxico e closures.
- `exercicios_aula_01.js`: exercícios para completar em aula.

## Meta da aula

Ao final, o estudante deve conseguir:

1. diferenciar igualdade abstrata e igualdade estrita;
2. criar, percorrer e transformar vetores;
3. declarar e chamar funções de diferentes formas;
4. passar e devolver funções;
5. reconhecer e construir um closure simples.
