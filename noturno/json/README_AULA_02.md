# TTI301 - Aula prática 2: objetos JavaScript

## Ordem da aula

1. Correção de `../introducao_javascript/exercicios_aula_01.js`.
2. Ponte entre closures e objetos com `../introducao_javascript/script9b.js`.
3. Objeto simples e acesso a propriedades: `script_pessoa.js`.
4. Objetos aninhados: `script_pessoa_com_endereco.js`.
5. Objeto com vetor de objetos: `script_concessionaria.js`.
6. Funções armazenadas em um objeto: `script_calculadora.js`.
7. Exercícios: `exercicios_aula_02.js`.

## Como executar

A partir da raiz do repositório:

```bash
cd noturno/json
node script_pessoa.js
node script_pessoa_com_endereco.js
node script_concessionaria.js
node script_calculadora.js
node exercicios_aula_02.js
```

Para executar o exemplo de transição:

```bash
cd ../introducao_javascript
node script9b.js
```

## Limite desta aula

O conteúdo desta aula termina em objetos JavaScript. A pasta
`../sincrono_assincrono` pertence ao bloco seguinte e não será utilizada nesta aula.
